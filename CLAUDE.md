# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A starter project for a JavaScript course exercise: a plain HTML/CSS/vanilla-JS front end (no bundler, no framework, no build step) that shows a list of transactions fetched from a mock REST API. `src/js/index.js` is empty; the task is to build the UI in it.

## Commands

```bash
npm install
npm run server   # json-server on http://localhost:3000, watching data/db.json
```

There are no build, lint, or test scripts.

To view the front end, serve the **repo root** with any static server (for example VS Code Live Server, or `npx serve .`) and open `/src/index.html`. `src/styles/fonts.css` loads fonts from the absolute path `/assets/fonts/...`, so serving from `src/` breaks the Vazirmatn font.

## API (json-server 0.17)

The only resource is `transactions` (`id`, `type`, `price`, `refId`, `date` as an epoch-ms timestamp). Writes through the API change `data/db.json` on disk.

Query patterns the task expects (from `docs/README.md`):

- Search by reference ID while the user types (on the `input` event): `GET /transactions?refId_like=<query>`
- Sort by price: `GET /transactions?_sort=price&_order=asc|desc`
- Combine them: `GET /transactions?refId_like=123&_sort=price&_order=asc`

The docs show `axios.get(...)`, but axios is not installed or loaded in `index.html`. Either add it (for example a CDN `<script>` before `index.js`) or use `fetch`.

## Front-end conventions

- The page is Persian and right-to-left (`<html lang="fa" dir="rtl">`), and transaction `type` values are Persian strings. Format dates and prices for the `fa-IR` locale.
- `html { font-size: 62.5% }`, so `1rem = 10px`. Size things in rem with that in mind.
- Use the design tokens on `:root` in `src/styles/index.css` (`--color-primary-*`, `--color-secondary-*`, `--border-radius-*`, and the status and red colors) instead of hard-coded values.
- `src/styles/fonts.css` is generated (`/* Generated by script */`). Don't edit it by hand.
