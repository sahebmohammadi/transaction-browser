# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A JavaScript course exercise: a vanilla-JS (ES modules, no framework, no bundler) transaction browser styled with Tailwind CSS v4, reading from a json-server mock API. Domain vocabulary lives in `CONTEXT.md`; decisions in `docs/adr/`.

## Commands

```bash
npm install
npm run dev        # json-server on http://localhost:3001 (also serves the repo root) + Tailwind watch
npm run seed       # regenerate data/db.json deterministically (scripts/seed.js)
npm test           # node:test unit tests in test/
npm run css:build  # one-off minified Tailwind build
```

Open `http://localhost:3001/src/index.html`. json-server serves the page itself (`-s .`), so the API is same-origin (`API_BASE = ""` in `src/js/constants.js`; from any other port, e.g. Live Server on :5500, it falls back to `http://localhost:3001`) and the absolute `/assets/fonts/...` paths in `fonts.css` resolve.

## API (json-server 0.17 — do not upgrade, see ADR 0001)

Resources: `users` (`id`, `name`, `phone`, `avatar` URL) and `transactions` (`id`, `refId`, `type`, `price` in Toman, `date` epoch-ms, `status` = `success|pending|failed`, `userId`). Writes through the API change `data/db.json` on disk.

All querying is server-side; `src/js/api.js` builds the params:

- Search box: digits only → `refId_like`, other text → `type_like` (regex-escaped); Persian/Arabic digits are normalized first.
- Filters: `type=`, `status=`, `userId=`. List adds `_sort`, `_order`, `_page`, `_limit=10`, `_expand=user`; total comes from `X-Total-Count`.
- Summary re-requests the same filters without paging and totals client-side (success only).

## Front-end conventions

- Persian, right-to-left. Numbers show Persian digits with a Latin comma every three digits (`formatAmount`); Reference IDs have no separators; dates are Jalali via `Intl` `fa-IR`.
- Components in `src/js/components/` are `fn(props) → HTMLElement` built with `el()` from `src/js/dom.js`. Never put data in `innerHTML`.
- No native `<select>`: use `Dropdown` (`src/js/components/Dropdown.js`), whose `control.value` reads/writes like a select's. Modals use `Dialog` (native `<dialog>`, bottom sheet on phones).
- `src/styles/index.css` is the Tailwind input; design tokens live in its `@theme` (`bg-primary-900`, `text-success`, `rounded-md`, …). `src/styles/output.css` is generated but committed. Write full class names as string literals so Tailwind can find them.
- Mobile-first: transaction cards below `lg` (2 columns from `md`), table at `lg`+.
- App state (search, filters, sort, page) is synced to the query string by `src/js/state.js`.
- `src/styles/fonts.css` is generated (`/* Generated by script */`). Don't edit it by hand.
